Direccionamiento IP y Servicios

IPv4, subnetting, y los tres servicios que mantienen viva cualquier red: DHCP para la asignación automática de IPs, DNS para resolver nombres de dominio, y NTP para sincronizar el tiempo en toda la infraestructura.

Teoría ampliada

¿Qué es una dirección IPv4?

Una dirección IPv4 es un identificador de 32 bits escrito en cuatro octetos decimales (ej: 192.168.1.10). Cada octeto equivale a 8 bits en binario. La dirección tiene dos partes: la porción de red (igual para todos los equipos del mismo segmento) y la porción de host (única por equipo). La máscara de red define dónde termina una parte y empieza la otra.

Redes privadas y públicas

Las IPs privadas no son enrutables en Internet y se usan dentro de las organizaciones:

Classless y subnetting

El sistema classless usa la notación de prefijo (CIDR) para definir exactamente cuántos bits pertenecen a la red. La fórmula para calcular hosts disponibles es 2^h − 2, donde h es el número de bits de host. Se restan 2 porque la primera IP es la dirección de red y la última es el broadcast.

DHCP — Dynamic Host Configuration Protocol

DHCP asigna automáticamente IP, máscara, gateway y DNS a cualquier equipo que se conecte. Funciona en cuatro etapas conocidas como DORA:

  • D — Discovery: El cliente envía un broadcast (src: 0.0.0.0, dst: 255.255.255.255) buscando un servidor DHCP.
  • O — Offer: El servidor responde ofreciendo una IP disponible con todos los parámetros.
  • R — Request: El cliente acepta formalmente la oferta enviando un broadcast (para notificar a otros servidores).
  • A — Acknowledge: El servidor confirma la asignación y anota la IP en su tabla de leases.
Ámbito DHCP (Scope) Un scope define el rango de IPs a distribuir, las IPs excluidas, el gateway, los DNS y el tiempo de arrendamiento (lease time). Si el lease expira y el cliente no renueva, la IP vuelve al pool disponible.

DNS — Domain Name System

DNS traduce nombres de dominio a direcciones IP. Cuando escribes canoacademy.com, tu equipo consulta al DNS configurado (por ejemplo 8.8.8.8) que resuelve el nombre a una IP. La estructura de un dominio tiene tres niveles: TLD (.com, .org, .net), SLD (el nombre comercial, ej: canoacademy) y el subdominio (ej: www).

NTP — Network Time Protocol

NTP sincroniza el reloj de todos los equipos de la red usando el puerto UDP 123. La sincronización es crítica para: correlación de logs de seguridad, certificados SSL, grabadores CCTV, teléfonos IP y backups programados. Los servidores NTP públicos están organizados en pools por región (do.pool.ntp.org para República Dominicana).

Diagrama — Flujo DHCP DORA

El proceso DORA ocurre en milisegundos. Discovery y Request son siempre broadcast. Offer y Acknowledge dependen del flag de broadcast del cliente (RFC 2131 §4.1): si está activo el servidor responde en broadcast; si no, puede responder en unicast a la dirección MAC del cliente incluso antes de que tenga IP asignada. En renovaciones el cliente ya conoce la IP del servidor y usa unicast directamente.

Laboratorio 3 — DHCP, DNS y NTP

  1. Abrir CMD: ipconfig /all — identificar IP, gateway, DNS y servidor DHCP asignado.
  2. Ejecutar ipconfig /release seguido de ipconfig /renew para observar el proceso DORA.
  3. Hacer ping canoacademy.com — observar qué IP devuelve el DNS.
  4. Ejecutar nslookup google.com para ver la resolución DNS en detalle.
  5. Abrir ajustes de fecha y hora → Sincronizar ahora. Cambiar la zona horaria y verificar la sincronización NTP.
  6. Calcular hosts disponibles en la red 10.0.0.0/22 usando la fórmula 2^h − 2.
Cálculo rápido /22 /22 deja 10 bits de host → 2^10 − 2 = 1022 hosts. Los prefijos /8, /16 y /24 son los más fáciles de recordar: 16 M, 65 K y 254 hosts respectivamente.

Flashcards

Haz clic en cada tarjeta para ver la respuesta.

¿Cuántos hosts útiles tiene una red /24?
254 hosts (2^8 − 2). Una /24 tiene 256 IPs pero la primera es red y la última es broadcast.
¿Qué significan las letras DORA en DHCP?
Discovery, Offer, Request, Acknowledge — las 4 etapas del proceso de asignación de IP por DHCP.
¿Qué hace DNS?
Traduce nombres de dominio (como google.com) a direcciones IP. Opera en el puerto 53 (UDP/TCP).
¿Qué puerto usa NTP?
UDP puerto 123. NTP sincroniza el reloj de los equipos con servidores de tiempo de alta precisión.
¿Cuál es el rango de IPs privadas clase C?
192.168.0.0 – 192.168.255.255. Clase A: 10.0.0.0/8. Clase B: 172.16.0.0 – 172.31.255.255.
¿Por qué se restan 2 al calcular hosts en una subred?
La primera IP es la dirección de red y la última es el broadcast — ninguna se puede asignar a un host.

Cuestionario

1. ¿Cuántos hosts útiles tiene la red 192.168.1.0/24?
2^8 − 2 = 254. Se restan la dirección de red (.0) y el broadcast (.255).
2. Las 4 etapas del DHCP son…
DORA: Discovery (cliente busca), Offer (servidor ofrece), Request (cliente acepta), Acknowledge (servidor confirma).
3. DNS opera principalmente en el puerto…
DNS usa el puerto 53 UDP (consultas pequeñas) y 53 TCP (zonas completas o respuestas largas).
4. NTP usa el protocolo de transporte…
NTP usa UDP puerto 123. Al ser sincronización de tiempo, prioriza la baja latencia sobre la fiabilidad.
5. La IP 172.20.5.10 pertenece al rango privado…
172.16.0.0 – 172.31.255.255 es el bloque B privado. 172.20.5.10 cae en ese rango.
