Conceptos y Protocolos de Red

Topologías, el modelo OSI, TCP/UDP, puertos, dominios de broadcast y colisión, VLANs, ARP y la tabla de direcciones MAC. El marco conceptual que explica cómo se comunican los equipos de red.

Topologías de red

La topología define cómo están físicamente o lógicamente conectados los equipos. Las más importantes son: BUS (todos comparten un mismo cable, obsoleta), RING (cada equipo se conecta al siguiente en círculo), STAR (todos conectan a un switch central — la más usada hoy), MESH (cada equipo tiene múltiples rutas, alta redundancia) y Peer to Peer (dos equipos directamente conectados).

Tipos de redes por alcance

  • LAN / WLAN: Red de área local dentro de un edificio o campus.
  • MAN: Red metropolitana que interconecta edificios en una misma ciudad, generalmente por fibra o radioenlaces.
  • WAN: Red de área amplia que conecta ciudades, países o continentes — es la red de Internet.

Modelo OSI — 7 capas

El modelo OSI describe cómo los equipos se comunican dividiéndola en 7 capas independientes. Cada capa tiene una responsabilidad específica y se comunica solo con la capa inmediatamente superior e inferior.

TCP vs UDP

TCP (Transmission Control Protocol) establece una sesión con el 3-way handshake (SYN → SYN/ACK → ACK) y confirma la entrega de cada segmento. Si un paquete se pierde, TCP lo retransmite. Es fiable pero más lento. Se usa para HTTP, SSH, FTP, correo.

UDP (User Datagram Protocol) envía datos sin establecer sesión ni confirmar entrega. Es más rápido y con menor latencia. Se usa para VoIP, DNS, DHCP, video streaming y juegos en tiempo real.

Para recordar TCP = Llamada telefónica (se establece la comunicación antes de hablar). UDP = Carta postal (se envía y no se sabe si llegó).

Dominios de broadcast y colisión

Un dominio de colisión es el segmento donde dos equipos pueden interferirse al transmitir simultáneamente. Los switches crean un dominio de colisión por puerto (full-duplex, sin colisiones). Los hubs crean un dominio de colisión único para todos los puertos.

Un dominio de broadcast es el conjunto de dispositivos que reciben tramas broadcast. Un switch sin VLANs tiene un solo dominio de broadcast. Los routers separan dominios de broadcast. Las VLANs crean dominios de broadcast lógicos dentro del mismo switch.

VLANs

Una VLAN (Virtual LAN) permite segmentar lógicamente los puertos de un switch. Los equipos en VLAN 10 no pueden comunicarse directamente con los de VLAN 20 sin un router o switch L3. Beneficios: seguridad, reducción de broadcast, flexibilidad y ahorro de costos.

ARP y MAC Address Table

El protocolo ARP resuelve una dirección IPv4 a su dirección MAC correspondiente. Cuando un equipo quiere comunicarse con una IP, envía un broadcast ARP preguntando "¿quién tiene esta IP?"; el dueño responde con su MAC.

El switch mantiene una MAC Address Table que asocia cada dirección MAC con el puerto por el que fue aprendida. Esta tabla es volátil (se borra al reiniciar). Si la MAC de destino no está en la tabla, el switch hace flooding por todos los puertos de esa VLAN.

Laboratorio 2 — Packet Tracer y escaneo de red

  1. Instalar Cisco Packet Tracer y crear una topología simple: 3 PCs conectadas a un switch.
  2. Asignar IPs estáticas a las PCs: 192.168.1.10, .11 y .12 con máscara /24.
  3. Verificar conectividad con ping 192.168.1.11 desde una PC.
  4. Abrir CMD en Windows, ejecutar ipconfig /all y localizar la MAC Address.
  5. Ingresar la MAC en macvendors.com para identificar el fabricante.
  6. Descargar Network Scanner (softperfect.com), escanear la red y listar todos los equipos activos.
Comandos útiles ipconfig /all — ver IP, MAC y DNS · ping 8.8.8.8 — probar conectividad · tracert google.com — ver el camino de los paquetes.

Flashcards

Haz clic en cada tarjeta para ver la respuesta.

¿Cuántas capas tiene el modelo OSI?
7 capas: Física, Enlace, Red, Transporte, Sesión, Presentación y Aplicación.
¿Qué protocolo garantiza la entrega de datos?
TCP — usa el 3-way handshake y confirmaciones ACK para garantizar que cada segmento llegue.
¿Qué puerto usa HTTP?
Puerto 80 (TCP). HTTPS usa el puerto 443. SSH usa el 22.
¿Qué hace el protocolo ARP?
Resuelve una dirección IPv4 a su dirección MAC, enviando un broadcast en la red local.
¿Qué separa los dominios de broadcast?
Los routers (capa 3) separan dominios de broadcast. Las VLANs crean dominios de broadcast lógicos dentro de un switch.
¿Qué es la topología STAR?
Todos los equipos se conectan a un switch central. Es la topología estándar en las redes locales actuales.

Cuestionario

1. ¿Cuántas capas tiene el modelo OSI?
OSI tiene 7 capas: Física, Enlace, Red, Transporte, Sesión, Presentación, Aplicación.
2. ¿Qué protocolo usa el 3-way handshake?
TCP usa SYN → SYN/ACK → ACK para establecer la sesión antes de enviar datos.
3. Una VLAN en un switch…
Las VLANs crean dominios de broadcast separados de forma lógica dentro del mismo switch físico.
4. El puerto 443 corresponde al protocolo…
HTTPS usa el puerto 443; HTTP usa el 80; SSH usa el 22; FTP usa el 20/21.
5. ARP resuelve…
ARP (Address Resolution Protocol) asocia una IP a la MAC del dispositivo en la misma red.
