Cómo encajan los seis módulos en una instalación de cableado estructurado real.

Cómo aprovechar este material

Ruta recomendada

  1. Lee la teoría de cada módulo y comprende el fundamento técnico.
  2. Identifica las herramientas y materiales mencionados en el módulo.
  3. Practica las técnicas de instalación antes de ir al campo.
  4. Repasa con las flashcards hasta responderlas sin dudar.
  5. Completa el cuestionario; si bajas del 70 %, vuelve a la teoría.

Qué incluye cada módulo

  • Teoría ampliada con el fundamento técnico de cada tecnología.
  • Tablas de materiales y comparativas de productos del mercado.
  • Técnicas paso a paso de instalación y terminación.
  • Diagrama de la topología del escenario del módulo.
  • Flashcards interactivas (clic para girar).
  • Cuestionario autoevaluable con explicaciones.

¿Para quién es este curso?

Cuatro perfiles profesionales que se benefician directamente de este curso.

DATA CENTER

Constructores de Data Centers

Si confeccionas data centers de manera empírica, este curso te da la formalidad y los estándares que necesitas para profesionalizar tu trabajo.

CAMERA

Integradores de CCTV IP

Toda tu red de cámaras depende de un cableado estructurado correcto. Aprende a instalarlo con las mejores prácticas del mercado.

DOMÓTICA

Integradores Domóticos

Los sistemas domóticos modernos corren sobre CAT6. Un buen cableado es la base indispensable de cualquier instalación domótica.

VOIP

Técnicos de Telefonía IP

Si integras centrales telefónicas IP, la calidad de voz depende directamente de la calidad del cableado. Este curso es tuyo.
