Guía de preparación

Requerimientos del curso

Todo el hardware, equipamiento y software que necesitas para seguir los tres cursos con laboratorios y prácticas reales.

💡
Nota: La mayoría del software es gratuito o de código abierto. El hardware físico puede sustituirse parcialmente con simuladores como Packet Tracer o GNS3 si aún no cuentas con equipo real.

Requerimientos generales todos los cursos

Equipo base recomendado para cualquiera de los tres cursos.

💻 Computadora / Laptop
  • CPU: Intel Core i5 / AMD Ryzen 5 o superior
  • RAM: 8 GB mínimo (16 GB recomendado para virtualización)
  • Almacenamiento: SSD de 256 GB o más
  • SO: Windows 10/11, Ubuntu 20.04+ o macOS 12+
  • Puertos: Al menos 1 puerto USB-A y acceso a red Ethernet (adaptador si es necesario)
🌐 Conectividad
  • Acceso a Internet: Para descargar software, firmware e imágenes IOS
  • Tarjeta de red Ethernet: Integrada o adaptador USB-RJ45
  • Switch básico: Opcional para prácticas de cableado en casa (cualquier switch no administrado de 4–8 puertos)
📱 Dispositivos adicionales (opcionales)
  • Smartphone / tablet: Para probar conectividad inalámbrica en prácticas WiFi
  • Segundo equipo: Útil para simular entornos cliente-servidor reales

Redes Básicas nivel básico

Equipo y software para los 6 módulos: OSI, TCP/IP, DHCP/DNS/NTP, WiFi, Proxmox y NAT/IPv6.

🖥️ Hardware para virtualización
  • CPU con VT-x / AMD-V: Virtualización por hardware habilitada en BIOS/UEFI
  • RAM: 16 GB para correr Proxmox y al menos 2 VMs simultáneas
  • Disco adicional: HDD/SSD secundario o USB 3.0 de 64 GB para instalar Proxmox
  • Servidor físico (opcional): PC de escritorio vieja o mini-PC para dedicar a Proxmox
📡 Equipo de red
  • Router doméstico: Cualquier router con acceso a la configuración DHCP/DNS
  • Access Point WiFi: Para módulo de redes inalámbricas (puede ser el propio router)
  • Cable UTP CAT5e/CAT6: 1–2 cables Ethernet para conexiones directas
🔧 Software simulación (alternativa física)
  • Cisco Packet Tracer: Simulador gratuito (requiere cuenta Cisco Networking Academy)
  • VirtualBox / VMware Player: Hipervisor gratuito para crear máquinas virtuales
  • Wireshark: Análisis de tráfico de red (gratuito)

Redes Avanzado nivel avanzado

Equipo para los 7 bloques: Cisco IOS, VLANs/STP, Ubiquiti, RADIUS, WiFi 802.1X, Multicast y Seguridad L2.

🔀 Switches administrables
  • Cisco Catalyst 2960 / 2960S: Switches de capa 2 para prácticas de VLANs y STP (recomendados para laboratorio físico)
  • Cisco Catalyst 3560 / 3750: Switch capa 3 para inter-VLAN routing y OSPF básico
  • Cable de consola RJ45-DB9 / USB: Para acceder al CLI de Cisco IOS
  • Cables UTP CAT5e/CAT6: Mínimo 4–6 cables para topologías multi-switch
📶 Infraestructura Ubiquiti
  • UniFi Access Point: AP UniFi UAP-AC-Lite, UAP-AC-Pro o similar para módulo WiFi empresarial
  • UniFi Switch (opcional): Switch PoE UniFi para alimentar APs sin fuente separada
  • Inyector PoE 802.3af: Alimentar el AP si no se tiene switch PoE
  • Servidor UniFi Network (Software): Gratuito; puede correr en PC local o VM Linux
🔐 Servidor RADIUS / AAA
  • FreeRADIUS: Servidor RADIUS gratuito; corre en Linux (Ubuntu/Debian recomendado)
  • VM o PC dedicado: Para instalar el servidor RADIUS y pruebas de autenticación 802.1X
  • Supplicant 802.1X: Windows 10/11 o Linux con wpa_supplicant para clientes de prueba
🖧 Simulación (sin hardware físico)
  • GNS3 + imágenes IOS-L2: Simulador avanzado para Cisco (requiere imágenes IOS reales)
  • EVE-NG Community: Alternativa a GNS3; corre como VM (gratuita en versión Community)
  • Cisco Packet Tracer: Para prácticas de VLANs y STP sin equipos físicos

Cableado Estructurado especialización

Herramientas, materiales y equipo para los 7 módulos: medios físicos, canalización, data center, campo de trabajo, fibra óptica, consideraciones profesionales y presupuesto de obra.

🔌 Materiales de cableado
  • Cable UTP CAT6 (bobina 25 m): Para prácticas de armado y ponchado
  • Conectores RJ45 CAT6: Pack de al menos 20 conectores para prácticas
  • Cable FTP/SFTP CAT6A (opcional): Para módulo de medios apantallados
  • Patch panel CAT6 (12/24 puertos): Para prácticas de terminación en panel
  • Keystone jack CAT6: Pack de 6–10 unidades para cajas de salida
🛠️ Herramientas de instalación
  • Ponchadora RJ45: Herramienta para crimpar conectores (8P8C)
  • Herramienta de impacto (punch-down): 110/88 para keystones y patch panels
  • Pelacable / decapador: Para preparar el cable sin dañar los pares
  • Tijeras para cable o cortacables: Corte limpio y nivelado
  • Destornilladores: Plano y Phillips para montaje en rack y cajas
  • Taladro / berbiquí (opcional): Para instalación en paredes y canalizaciones
🧰 Herramientas de medición y prueba
  • Tester de cable básico: Verificar continuidad y mapa de pines en cobre
  • Certificador de red (avanzado): Fluke DSX-5000 o similar para certificación CAT6/6A (laboratorio profesional)
  • Trazador de cable (tone generator): Para identificar cables en canalizaciones
  • Nivel de burbuja: Montaje nivelado de racks y canalizaciones
  • Cinta métrica: Medición de tendidos y recorridos
🔦 Fibra óptica
  • Cable fibra multimodo OM3/OM4: Tramo corto (2–5 m) para prácticas de identificación
  • Conectores LC/SC prepolidos (mecánicos): Pack de 4–6 para práctica de terminación en frío
  • Cleaver de fibra (cortadora): Para corte perpendicular de fibra
  • Visual Fault Locator (VFL): Localizador de fallas visible (lápiz rojo láser) para multimodo
  • Optical Power Meter (OPM): Medición de pérdida de inserción en enlaces de fibra
  • Patch cords LC-LC / SC-SC: Para prácticas de conexión en ODF
🗄️ Infraestructura de rack / data center
  • Rack abierto 6U–12U (mini): Para practicar montaje y organización de un cuarto técnico a escala reducida
  • PDU básica (regleta para rack): Distribución de energía en el rack
  • Organizadores de cable 1U: Guías horizontales de cable para mantener orden
  • Patch cords de colores: Cat6, varios colores para identificación de VLANs / circuitos
📐 Canalización y campo de trabajo
  • Canaleta plástica 20×12 mm / 40×25 mm: Para prácticas de tendido ordenado
  • Cajas de salida dobles/cuádruples: Para terminaciones en puestos de trabajo
  • Etiquetas autoadhesivas: Rotulación de cables, puertos y circuitos (norma TIA-606)
  • Bridas / amarres de cables: Pack de plástico y velcro para organización

Configuración mínima recomendada por curso

Si tu presupuesto o acceso a equipo es limitado, aquí está lo esencial para empezar.

🟢 Redes Básicas — Mínimo indispensable

  • Laptop/PC con 8 GB RAM y Windows 10 o Ubuntu
  • VirtualBox instalado para crear VMs
  • Cisco Packet Tracer (cuenta gratuita Cisco NetAcad)
  • Wireshark para análisis de tráfico
  • Acceso al router doméstico para laboratorios DHCP/DNS

🔵 Redes Avanzado — Mínimo indispensable

  • Laptop/PC con 16 GB RAM (para GNS3 o EVE-NG en VM)
  • Cisco Packet Tracer para VLANs y STP básico
  • GNS3 con imagen IOSvL2 para laboratorios avanzados
  • VM Ubuntu Server con FreeRADIUS para módulo RADIUS/802.1X
  • 1 AP UniFi real o simulación en UniFi Network App

🟡 Cableado Estructurado — Mínimo indispensable

  • 1 m de cable UTP CAT6 y 4 conectores RJ45 para ponchado básico
  • Ponchadora y pelacable manuales
  • Tester de cable básico para verificar continuidad
  • 2 keystones CAT6 y una caja de salida doble
  • draw.io para documentar planos de tendido
